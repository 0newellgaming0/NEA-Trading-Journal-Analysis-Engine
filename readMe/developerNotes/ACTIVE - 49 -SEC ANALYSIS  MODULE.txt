# NEA28 SEC Financial Intelligence System

## Master Architecture & Plugin Specification

---

# Overview

The NEA28 SEC Financial Intelligence System is an institutional-grade SEC EDGAR analysis framework designed to extract, normalize, analyze, and score company fundamentals directly from SEC XBRL filings.

The system is modular, extensible, and plugin-driven.

Rather than placing all analysis inside a single engine, responsibilities are separated into specialized analysis plugins orchestrated by `SECAnalysisExtensions`.

This architecture allows every financial discipline to remain isolated while producing a unified institutional analysis.

---


---

# Design Philosophy

Every plugin has one responsibility.

No plugin duplicates calculations performed by another plugin.

Every plugin operates exclusively from normalized SEC XBRL facts.

Each plugin returns structured dictionaries suitable for downstream engines.

Plugins never modify SEC data.

Plugins never access the repository directly.

Plugins receive normalized DataFrames from SECAnalysis.

# SECAnalysisExtensions

SECAnalysisExtensions is the orchestration layer.

Responsibilities

* Execute every plugin
* Preserve plugin isolation
* Aggregate plugin outputs
* Return unified institutional analysis
* Provide downstream data to Growth Asymmetry, Institutional Ranking, CANSLIM, ML Feature Generation, and UI components

Plugins never call one another directly.

SECAnalysisExtensions coordinates execution order and dependency management.

---

# Plugin Development Standards

Every plugin shall adhere to the following standards:

* One complete `.py` module per implementation response.
* Compact formatting with no excessive whitespace or unnecessary blank lines.
* Consistent NEA28 module headers and documentation.
* Institutional-grade SEC/XBRL concept priority lists.
* Robust handling of duplicate SEC facts.
* Safe fiscal period and fiscal year matching.
* Consistent return dictionary structures.
* No duplicated business logic across plugins.
* Pure analytical logic with no repository or UI dependencies.
* Compatible with `SECAnalysisExtensions` orchestration.
* Deterministic outputs suitable for scoring engines, machine learning features, and institutional screening.
