```python
    "analysis_type": "",
    "latest": {},
    "metrics": {},
    "classification": "",
    "score": 0,
    "history": [],
    "metadata": {}

```

Output requirements:

* Always return dictionary
* Never return None
* Missing data returns empty structures
* Errors are logged
